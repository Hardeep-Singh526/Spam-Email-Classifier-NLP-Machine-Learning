## 📌 Overview

SentinelAI is an AI-powered Spam Email Classifier that combines **Machine Learning** and **Google Gemini AI** to detect spam, phishing attempts, and suspicious emails.

The application first preprocesses the email using Natural Language Processing (NLP) techniques and predicts whether the email is **Spam** or **Legitimate** using a Machine Learning model. It then leverages Google Gemini to generate an intelligent explanation, identify phishing indicators, and provide actionable cybersecurity recommendations.

This project demonstrates end-to-end AI application development, including NLP, Machine Learning, Generative AI integration, and a modern web interface.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/Hardeep-Singh526/Spam-Email-Classifier-NLP-Machine-Learning.git

cd Spam-Email-Classifier-NLP-Machine-Learning
```

## Install Dependencies

```bash
npm install
```

## Environment Variables

Create a `.env` file.

```
GEMINI_API_KEY=YOUR_API_KEY
```

## Run Application

```bash
npm run dev
```
